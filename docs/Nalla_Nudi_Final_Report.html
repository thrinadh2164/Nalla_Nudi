Abstract

This report details the development of Nalla-Nudi, a specialized technical dictionary application built for the Android ecosystem. The project addresses a critical gap in rural education: the language barrier faced by students moving from Kannada-medium primary education to English-medium technical courses.

The application leverages modern Android technologies, including Kotlin, Jetpack Compose (Material 3), and Room Database for offline-first architecture. Key features include a bilingual search engine, an AI-powered translation fallback, and a phonetics-optimized Voice Guide. Through systematic development phases—from database schema design to UI responsiveness optimization—the project achieved a high-performance tool capable of providing technical definitions in under 200ms. This report outlines the technical stack, implementation logic, and final outcomes of the internship.

Chapter 1: Introduction

1.1 Project Vision

The Nalla-Nudi project was envisioned as a digital "bridge" for students. In the current educational landscape, technical terms in Science, Mathematics, and Computer Science are often overwhelming for students with a non-English background. This project aims to simplify these terms using familiar Kannada contexts.

1.2 Objectives
  • Develop a high-speed, offline technical dictionary.
  • Implement a bilingual UI supporting both English and Kannada natively.
  • Integrate Text-To-Speech (TTS) for technical pronunciation.
  • Ensure the interface follows Material Design 3 guidelines for a premium user experience.

Chapter 2: Tasks Performed

2.1 Phase 1: Foundation & Architecture

The initial weeks focused on setting up the Android environment using Gradle 8.x and Kotlin 1.9. This included configuring the project manifest and establishing the MVVM (Model-View-ViewModel) design pattern.

2.2 Phase 2: Data Persistence (Room DB)

Designed the SQL database schema for technical terms. Implemented Data Access Objects (DAOs) to handle complex queries across subjects like Commerce, Science, and Math.

2.3 Phase 3: UI & Educational Features

Developed the main search dashboard, the Flashcard revision system, and the "Word of the Day" logic. Focused on creating custom vector assets and glassmorphic UI elements.
